open source

Lo sviluppo web ha sempre tratto giovamento dal mondo dell'open source . Credo fortemente nella filosofia dell'open source ma una distinzione però è fondamentale: open source non vuol dire gratuito, ma bensì la possiblità di avere accesso al codice sorgente. Questo è fondamentale per apprendere e per offrire un prodotto migliore ai clienti, sapendo che a quei componenti software ci hanno lavorato più persone.

Spesso, quando ne ho la possibilità, contribuisco a progetti open source tramite Pull Request.

I progetti più importanti dei quali sono Collaboratore sono:

Laravel
Framework di riferimento del mondo PHP, non servono altre presentazioni.
In particolare, ho contribuito ad Eloquent, il motore ORM del framework.

tailwindcss
tailwindcss è un CSS framework basato su classi utility che permette una altissima configurabilità.
Ho contribuito al framework realizzando alcuni classi dedicate al box-sizing.
